Exercise 2:
HTML برای ساختار و محتوای صفحه وب استفاده می‌شود.
CSS برای ظاهر و طراحی صفحه وب استفاده می‌شود.
JavaScript برای ایجاد رفتار و تعامل در صفحه وب استفاده می‌شود.


Exercise 3:
Web Server سیستمی است که درخواست‌های Client را دریافت می‌کند
و اطلاعات یا صفحات موردنظر را برای آن ارسال می‌کند.
Apache و Nginx از نمونه‌های Web Server هستند.


Exercise 4:
Host فضایی روی یک Server است که فایل‌ها و اطلاعات سایت در آن قرار می‌گیرند.
Domain آدرس سایت است که کاربران برای ورود به سایت از آن استفاده می‌کنند.


Exercise 5:
DNS مخفف Domain Name System است.
DNS نام Domain را به آدرس IP مربوط به Server تبدیل می‌کند.


Exercise 6:
Client برنامه یا دستگاهی است که درخواست را ارسال می‌کند،
مثل مرورگر.
Server درخواست را دریافت و پردازش می‌کند و پاسخ می‌دهد.


Exercise 7:
Request درخواستی است که Client برای Server ارسال می‌کند.
Response پاسخی است که Server در جواب Request برای Client ارسال می‌کند.

مثلاً:
Browser → Request → Server → Response → Browser


Exercise 8:
API مخفف Application Programming Interface است.
API روشی برای ارتباط و تبادل اطلاعات بین نرم‌افزارها و سیستم‌های مختلف است.
مثلاً یک برنامه می‌تواند از Weather API برای دریافت اطلاعات آب‌وهوا استفاده کند.
